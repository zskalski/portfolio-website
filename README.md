# Personal Portfolio Website

This project is a personal portfolio website built with HTML and CSS to showcase my education, research experience, technical projects, resume, and contact information.

This site is designed as a professional portfolio for employers, recruiters, and collaborators who want to quickly understand my background, technical interests, and experience as a Computer Science student.

## Live Website

View the deployed website here:

https://zachskalski.com

## Overview

This portfolio introduces my background as a Computer Science student at Florida State University with interests in systems programming, low-level software, networking, distributed systems, embedded systems, defense technology, and aerospace software.

The site includes sections for:

- Education
- Research experience
- Projects
- Work experience
- About me
- Resume
- Contact information

## Features

- Multi-page static website
- Custom HTML and CSS design
- Navigation between major portfolio sections
- Dedicated about page with technical interests and hobbies
- Research experience section highlighting AI systems work
- Resume page with linked resume PDF
- Contact page with a contact form
- Custom domain deployment
- Basic SEO support using `robots.txt` and `sitemap.xml`

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Cloudflare DNS

## Skills Demonstrated

This project demonstrates:

- Structuring a multi-page website
- Writing semantic HTML content
- Organizing site navigation across multiple pages

- Managing static assets such as images and PDFs
